Development journal

This project explores an independent reimplementation of God Hand’s engine in Rust and Bevy. The source is open; game data must come from each user’s own ISO.

It is early. The game is not playable in this engine. This page records technical decisions, small steps and what we still need to understand.

2026-11-03

Choosing the direction

The initial idea was a PS2 recompilation port. After reviewing existing projects, the choice is to try an independent reimplementation in Rust and Bevy.

  • The engine will use original public MIT code.
  • Game data stays in each user’s own ISO.
  • Observations and specifications must be separated from implementation.
Checks and limitations

Reviewed PS2Recomp, ps2-web-recomp and ps2-native-recomp as research references.

God Hand compatibility reported by ps2-native-recomp is not our engine’s result. Game logic and formats still need to be understood.
