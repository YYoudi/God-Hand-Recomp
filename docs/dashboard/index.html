Carnet de développement

Ce projet explore une réimplémentation indépendante du moteur de God Hand en Rust et Bevy. Le code est ouvert ; les données du jeu devront venir de l’ISO personnelle de chaque utilisateur.

On en est au début. Le jeu n’est pas jouable dans ce moteur. Cette page rassemble les choix techniques, les petites avancées et ce qui reste à comprendre.

2026-11-03

Premier test de ps2-native-recomp

Le backend tiers construit depuis notre ISO atteint le premier combat de God Hand. C’est un résultat de ps2-native-recomp, pas du moteur Rust/Bevy.

  • Construction locale du runner, sans modifier les sources du backend.
  • Écran titre, cinématique et premier combat observés.
  • État du runtime enregistré puis rechargé ; la session continue avec des commandes programmées.

Lire le compte rendu de l’essai

Vérifications et limites

Un essai en fenêtre a parcouru 7 200 frames en 122,44 secondes. Un second a vérifié le mode normal à plusieurs threads et la création d’un état. La reprise a continué jusqu’à la limite prévue. Bilan détaillé dans docs/native-evaluation-2026-11-03.md du dépôt.

Essai court, sans validation du casino ou du jeu complet. Pause, manette physique et sauvegarde native du jeu restent à tester. Les captures de gameplay, données et traductions restent locales.

2026-11-03

Mise en ligne du dépôt

Le code et ce carnet sont maintenant publics sur GitHub. La roadmap reste dans le dépôt ; elle décrit les travaux envisagés, pas des fonctionnalités déjà présentes.

  • Sources originales sous MIT, avec les règles de provenance.
  • Publication du carnet sur GitHub Pages gratuit, sans statistiques ni éléments du jeu.
Vérifications et limites

Les contrôles GitHub passent : tests synthétiques, formatage, compilation Bevy sous Ubuntu et contrôle des fichiers publics. La page publiée a été vérifiée dans le navigateur.

Il n’y a pas encore de résultat de gameplay. Le bac à sable graphique est seulement vérifié à la compilation.

2026-11-03

Premiers fichiers du moteur

Le dépôt contient un petit lecteur ISO en lecture seule et les premières bases Rust. Rien du jeu ne tourne encore.

  • Lecture de la racine ISO 9660 et reconnaissance du disque USA.
  • Tests sur des images synthétiques, sans fichiers du jeu.
  • Préparation d’un sandbox Bevy avec un sol et une capsule.
  • Carnet de développement sobre, sans statistiques de progression.
Vérifications et limites

Tests Rust et compilation du viewer Bevy vérifiés sur Windows GNU. Le lecteur reconnaît aussi l’ISO locale : volume GODHAND, six entrées racine.

Le viewer n’a pas été exécuté. Aucune scène, animation ou logique du jeu n’est chargée.

2026-11-03

Choix de la direction

L’idée initiale était un port par recompilation PS2. Après examen des projets existants, le choix est de tenter une réimplémentation indépendante en Rust et Bevy.

  • Le moteur sera du code original public sous MIT.
  • Les données du jeu resteront dans l’ISO fournie par chaque utilisateur.
  • Les observations et spécifications devront être séparées de l’implémentation.
Vérifications et limites

Les projets PS2Recomp, ps2-web-recomp et ps2-native-recomp ont été examinés comme références de recherche.

La compatibilité God Hand rapportée par ps2-native-recomp n’est pas un résultat de notre moteur. La logique et les formats du jeu restent à comprendre.
