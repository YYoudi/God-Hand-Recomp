# État de l'art PS2 → PC au 3 novembre 2026

## Le lien God Hand

[ps2-native-recomp](https://github.com/exoteric33/ps2-native-recomp) rapporte God Hand
testé jusqu'au casino par theraineydaze. Ce n'est ni un parcours complet ni une
validation locale ; édition précise et machine ne figurent pas dans cette ligne.

Le projet traduit l'EE en C++ et émule le reste de la console. Ses sources contiennent
aussi la compilation pendant l'exécution des blocs EE/VU manquants : tous les chemins
ne sont pas nécessairement compilés hors ligne. L'auteur décrit des performances
inférieures à PCSX2 dans ses propres mesures.
Snapshot local : cba42f57913d181b3ff2fd3064ca48ab0cbeea11.

C'est une piste très pertinente pour jouer via recompilation, mais pas une
réimplémentation indépendante. L'utilisateur a finalement retenu Rust + Bevy.

## Comparaison

| Projet | Apport documenté | Usage ici |
| --- | --- | --- |
| [PS2Recomp](https://github.com/ran-j/PS2Recomp) | ELF → C++, analyse, runtime expérimental ; GPL-3.0 | Ancien setup local |
| [ps2-web-recomp](https://github.com/snuri00/ps2-web-recomp) | EE → C++/Wasm, runner natif ; MIT | Origine de la famille native |
| [ps2-native-recomp](https://github.com/exoteric33/ps2-native-recomp) | Runtime wgpu/SDL, résultat God Hand rapporté ; MIT | Essai de recomp envisageable |
| [GT4Recomp](https://github.com/moesuito/gt4-staticrecomp) | Port spécialisé GT4, EE/VU AOT, GS séparé selon README | Exemple, aucun support God Hand établi |
| [Urban Reign](https://github.com/thiagordsfx/urban-reign-recomp) | Port spécialisé, rendu PCSX2 ; GPL-3.0 | Exemple de fonctionnalités |
| [Bevy](https://bevy.org/news/bevy-0-20/) | Moteur Rust ECS, rendu et entrées ; stable 0.20.1 | Socle indépendant retenu |

Les résultats des autres ports sont ceux de leurs auteurs, pas des tests indépendants
effectués ici. Les architectures, ABI, formats et licences ne sont pas interchangeables.
Cette recherche publique ne constitue pas un classement exhaustif. Aucun résultat
de recompilation ne prouve du gameplay dans notre moteur Bevy.
