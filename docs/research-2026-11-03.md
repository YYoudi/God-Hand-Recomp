# PS2 → PC research snapshot, 3 November 2026

## The God Hand report

[ps2-native-recomp](https://github.com/exoteric33/ps2-native-recomp) reports God Hand
tested as far as the casino by theraineydaze. This was neither a full playthrough
nor our local validation at initial review. The row does not state the exact edition
or test machine.

The project translates EE code to C++ and emulates the rest of the console.
Its sources also compile missing EE/VU blocks during execution; not every path is
necessarily compiled offline. The author reports lower performance than PCSX2 in
their own measurements.
Reviewed snapshot: cba42f57913d181b3ff2fd3064ca48ab0cbeea11.

This is a relevant route for playing through recompilation, but not an independent
engine. The user selected Rust + Bevy for that separate goal.
A later [local trial](native-evaluation-2026-11-03.md) reached the first fight.

## Comparison

| Project | Documented contribution | Use here |
| --- | --- | --- |
| [PS2Recomp](https://github.com/ran-j/PS2Recomp) | ELF → C++, analysis, experimental runtime; GPL-3.0 | Historical local setup |
| [ps2-web-recomp](https://github.com/snuri00/ps2-web-recomp) | EE → C++/Wasm, native runner; MIT | Origin of the native family |
| [ps2-native-recomp](https://github.com/exoteric33/ps2-native-recomp) | wgpu/SDL runtime, reported God Hand result; MIT | Local executable reference |
| [GT4Recomp](https://github.com/moesuito/gt4-staticrecomp) | GT4-specific port, EE/VU AOT and separate GS according to README | Example; no established God Hand support |
| [Urban Reign](https://github.com/thiagordsfx/urban-reign-recomp) | Game-specific port with PCSX2 rendering; GPL-3.0 | Feature reference |
| [Bevy](https://bevy.org/news/bevy-0-20/) | Rust ECS engine, rendering and input; stable 0.20.1 at review time | Selected engine foundation |

Other ports' results are their authors' claims, not independent tests performed here.
Architectures, ABIs, formats and licenses are not interchangeable.
This public-source review is not exhaustive. Recompilation results do not establish
gameplay in our Bevy engine.
