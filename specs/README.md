# Independent specifications

Each contract describes observable behavior, not the original program. Include:

- task ID, version, author and date;
- provenance: public standard or external observation protocol;
- inputs, outputs, units and edge cases;
- separate observations, assumptions and tolerances;
- synthetic tests and acceptance criteria;
- disclosure of exposure to the original component's code.

Current reader: [ECMA-119](https://ecma-international.org/publications-and-standards/standards/ecma-119/),
primary descriptor at sector 16, 2048-byte blocks, directory records and numbers
in both byte orders. Supported subset: ISO 9660 root without Joliet, Rock Ridge,
extended attributes or interleaving. Extents are checked against file size.
No writes or extraction.

SLUS_215.03 is a public compatibility identifier, not an algorithm taken from the game.
Sandbox constants are provisional original choices.
No gameplay specification has been validated.
